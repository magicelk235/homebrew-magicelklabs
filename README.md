# magicelklabs Homebrew tap

Homebrew casks for [magicelk labs](https://magicelklabs.com) apps.

## Install

```sh
brew install --cask magicelk235/magicelklabs/viaduct
```

Or tap first, then install:

```sh
brew tap magicelk235/magicelklabs
brew install --cask viaduct
```

## Apps

| Cask | Description |
|------|-------------|
| [`viaduct`](Casks/viaduct.rb) | Converts Chrome extensions to native Safari extensions |
